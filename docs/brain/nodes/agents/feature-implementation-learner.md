# Feature Implementation Learner

Records compact reusable pattern cards after validated feature engineering changes.

Invoke for: feature logic changes, join strategy changes, lookup key design, column contract changes, derived feature semantics, feature validation patterns, failed feature approaches worth remembering.

Skip for: docstring-only tasks, pure formatting, non-reusable edits, simple Q&A, graph UI help.
